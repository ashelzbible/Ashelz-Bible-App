# Data safety form, answers to start from

This is a draft built from what the app really does. Read it against the privacy policy page, and check each answer yourself in Play Console, App content, Data safety. Google's wording changes, and how data laws apply is to be confirmed with the relevant legal bodies, authorities and entities of Namibia.

## What the app does with data
- Your name, prayers, notes, journal, favourites, profile picture and settings are saved only in the phone's own storage. They are not sent to the developer or to any server of ours.
- There is no account system, no ads, no analytics, and no sale of data.
- To show content, the app asks outside services for it. Those services can see the request and the internet address of the phone, as any website can: Bible text services (bible-api.com, GitHub and jsDelivr, bible.helloao.org, Biblia.com, and API.Bible only if the reader adds their own key), YouTube (only when a video is opened), Open Library and Project Gutenberg (book covers), Google (only for the optional Sign in with Google), and Jitsi Meet (only inside an Online Homecell meeting).
- The developer publishes devotions to the app's own website. Readers send nothing.

## Suggested answers
1. Does your app collect or share any of the required user data types? Data processed only on the phone is not "collected" under Google's definition. A careful answer is **No data collected**, as long as you are comfortable that the outside services above only receive ordinary requests. If you prefer to be cautious, you can instead declare the items in section 3.
2. Is all of the user data collected by your app encrypted in transit? **Yes.** Every outside address the app uses is https.
3. Cautious option, if you decide to declare: Personal info (name, email) only with the optional Google sign in, used for App functionality, not shared, optional. Photos, videos, camera and microphone are used only when the reader chooses (Homecell, profile picture), are not collected by the developer, and are optional.
4. Do you provide a way for people to request that their data is deleted? There is no account. Everything is on the phone, and the page https://ashelzbible.github.io/Ashelz-Bible-App/privacy.html?delete explains how to remove it. Use that link where Play asks for a deletion link.
5. Independent security review: **No**.
6. Committed to follow the Play Families Policy: **No**, the app is a general audience app.

## Check these if the app changes
- Adding ads, analytics, crash reporting, or a sign in server changes the answers.
- Letting readers post would add user generated content rules.
