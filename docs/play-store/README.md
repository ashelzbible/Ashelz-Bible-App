# Putting Ashelz Bible App on Google Play

Do these in order. Nothing here is legal advice, and nothing claims approval by Google or any other body.

1. Create the Play developer account (personal, about US$25 one time) and finish the ID checks. Only you can do this.
2. Check the live pages open: privacy.html and privacy.html?delete on the app address.
3. Package the app: android_wrapper.md. Create the `ashelzbible.github.io` repository with assetlinks.json.
4. Upload the `.aab` to a Closed testing track and run closed_test.md.
5. Fill the store listing (store_listing.md), the Data safety form (data_safety.md) and the content rating (content_rating.md). Upload the pictures from the graphics folder.
6. After the test period, apply for production in Play Console.
